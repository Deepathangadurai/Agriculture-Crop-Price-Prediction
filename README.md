# 🌾 Agriculture Crop Price Prediction

An AI-powered Machine Learning system that predicts **crop prices and production** using historical agricultural data, cultivation area, production costs, and seasonal trends.

Built using **Python**, **Scikit-learn**, and **Streamlit**, this project leverages a **Random Forest Regressor** model to generate accurate predictions through an interactive web application.

---

## 📘 Overview

This project is designed to assist farmers, agricultural analysts, and policy-makers by providing intelligent insights into future crop prices and production.

The system analyzes multiple agricultural factors, including:

* Area cultivated
* Cost of cultivation
* Year and season
* Crop type and region

Using these features, the model predicts the **expected market price or production output** to support data-driven agricultural decisions.

---

## 🧠 Machine Learning Model

* **Algorithm Used:** Random Forest Regressor
* **Problem Type:** Supervised Machine Learning (Regression)
* **Purpose:** Predict crop prices and production values based on historical agricultural data.

The Random Forest Regressor was selected because it effectively handles non-linear relationships, reduces overfitting, and provides reliable predictions on complex agricultural datasets.
